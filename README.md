# Arcaea Practice

Arcaea 非官方练习插件源码。当前版本：**外置数据壳子版 6.13.10c-r8**、**Arc701 外置数据壳子版 7.0.1c-r1**、**一体版 7.0.1f-r15**。

本仓库发布插件 Java/C++ 源码、构建工具、测试和脱敏验证记录。安装 APK 与游戏数据包需要自行准备。

## 功能

- 播放倍速以 0.01 调节；可选择倍速是否改变音高、谱面流速是否跟随倍速。
- 高刷新率平滑同步：预备完成与暂停恢复后不逐帧吸附音乐缓冲位置，减少重复音频接口调用。
- 高质量变速音频缓存，保留原调或可选变调；1.00× 直接播放原音乐。
- 自动播放、片段循环、重播，以及绝对时长三秒的片段预备阶段。
- 原生谱面可视化时间轴；拖动时不进行判定，并恢复起点之前的 camera / scenecontrol 状态。
- 练习面板透明度及入口按钮透明度调整。
- ZIP 谱面导入，校验 AFF、音乐、曲绘与背景名，保留已有歌曲和作者信息。
- 歌曲、曲包和分类管理；新建、移动、删除和最近一次修改撤销；songlist 采用 UTF-8 与 4 空格缩进。
- 独立曲包管理页，默认封面生成，上传图片等比放大与居中裁剪，原生封面缓存更新。
- 全曲背景 / 轨道替换和恢复，以及替换模式下的 6K 轨道兼容处理。

## 使用说明

右上角「＋导入谱面」提供导入及曲包管理入口。新建曲包后可以导入歌曲并上传封面。添加或修改曲库后，返回主界面再进入选曲，原生曲包入口和封面即可刷新。

自建分类显示在插件管理页左侧；原生左栏仍使用游戏固定分类，自建分类中的曲包映射至 Arcaea。删除操作移除目录条目，保留资源以支持撤销。只有 Beyond 等难度、没有 Past 的自建曲包，也能通过原生卡片进入歌曲列表。

一体版干净离线账户仍可能出现原生谱面解锁提示；本次没有修改谱面解锁规则。完整验证边界见 [VALIDATION.md](VALIDATION.md)。
