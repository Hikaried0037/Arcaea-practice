这是直接注入 APK 的 ARM64 练习插件，包含 Java 练习面板和原生谱面/音频hook，仅匹配Infinity 7.0.1f；构建脚本会检查原生库哈希，运行时检查函数入口<br><br>
安装与使用<br><br>
分享包包名为 moe.inf.arc.practice，与原包 moe.inf.arc 不同，可并存安装。完整包保留原有歌曲、谱面、图片及原插件库，适用于 Android 7.0 及以上的 ARM64 设备
改包使用独立签名。并存版本拥有独立存档，不会自动继承原版数据，无需卸载原版
1. 点击右上角 ◇ PRACTICE 打开面板
2. 设置 A 起点和 B 终点，单位为秒，支持小数。B 必须比 A 晚至少 1 秒。曲目播放时也可用“标记 A / 标记 B”取当前时间
3. 点击“应用时间”，开启“练习模式”。已在曲目中时，点击面板下方“重播片段”进入片段；选曲前开启则在进入曲目时跳到起点前
4. 开启“A → B 循环”后，到 B 点重新加载谱面并回到 A 点前 3 秒。加载有短暂过场
5. “自动播放”用于演示；关闭后可手动练习。起点前的预备段会自动处理音符
6. 速度范围为 0.25–2.00 倍，同时改变音乐播放速度和谱面时间推进速度。可使用 0.50 / 0.75 / 1.00 / 1.25 / 1.50 倍快捷按钮。面板可上下滚动，重播按钮在下方
片段跳转及切换倍速后，会根据实际音乐播放位置重新校准谱面时间，以处理音频跳转的缓冲延迟<br>
练习中采用重新创建场景和谱面的方式恢复音符及事件，并顺序推进起点前的状态。练习结束不进入普通成绩结算。关闭练习后，请退出当前曲目并重新选曲<br>
当前屏幕分数与连击可能包含起点前的状态推进和预备段，不是独立的片段成绩<br><br>
说明<br>
- 这是针对单一 APK 的实验版本，不能直接用于其他版本或 32 位设备
- 变速同时改变音高
- 重播会重新加载场景，不是无缝循环。复杂Camera事件、角色技能、特殊剧情谱面尚未逐一验证；原生pv的速度也可能与音乐变速不同
- 自动播放可以击打地键、长条、Arc 和 ArcTap，不保证所有非标准音符或自定义特殊判定
- A/B 与速度仅在当前运行中有效。练习面板沿用游戏字体和淡紫半透明配色，属于覆盖在游戏上的界面
- 文件名包含 test 的 APK 是模拟器测试包，部分歌曲音频替换为静音以减少体积，不应作为普通安装包<br><br>
源码：java/moe/practice/PracticeOverlay.java、native/practice.cpp<br>
源码包为 source/Arcaea-Practice-source.zip，包含插件源码、可配置的 Windows 构建脚本及检查脚本；具体依赖、构建命令和签名说明见源码包中的 practice/BUILDING.md；原始游戏 APK、第三方工具和发布者签名私钥不包含在源码包中；<br>
输入包中的 libarcinf.so 会保留。新增 libarcpractice.so、classes4.dex，修改 classes2.dex 中的 Activity、分享 Provider、BuildConfig 与渲染入口，不修改原游戏原生库文件。Manifest 的包名、Provider 地址、自定义权限、任务标识和资源表包名一起改为新包名，资源 ID 和 Java/JNI 类名保留；<br>
build.ps1 默认构建并存版。若需要指定其他包名，可传入 -PackageName
